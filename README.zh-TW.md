# 類生化體術 · 玩家回報

這裡收集《殭屍毀滅工程》類生化體術系列的意見。體術、閃避、受擊反應和武術套路都可以在這裡回報。

- [回報問題](https://github.com/rgayuurp-del/BioStyle-Feedback/issues/new?template=bug-zh-TW.yml) · 說明你做了什麼，以及遊戲裡發生了什麼。
- [玩法建議](https://github.com/rgayuurp-del/BioStyle-Feedback/issues/new?template=idea-zh-TW.yml) · 告訴我們你希望怎麼調整招式或操作。
- [查看既有回報](https://github.com/rgayuurp-del/BioStyle-Feedback/issues) · 如果有人已回報相同問題，歡迎在原議題補充手持武器、操作順序或重測結果。

截圖、短影片和相關日誌片段都可選填。內容將公開，請先遮蔽帳號、伺服器位址等私人資訊。也歡迎直接在 Steam 工作坊留言。
